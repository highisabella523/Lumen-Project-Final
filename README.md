# 🚀 Panel

## 🌐 تنظیم آیپی خروجی

هر کانفیگ مستقل می‌تواند Direct، یک پروکسی مدیریت‌شده از مخزن، یا پروکسی دلخواه داشته باشد. مخزن خصوصی با AWS Signature V4 خوانده می‌شود و هر ۲ ساعت به‌روزرسانی می‌شود. مخزن HTTP/HTTPS/SOCKS5 را می‌پذیرد و Endpointهای مدیریت‌شده به مرورگر ارسال نمی‌شوند؛ کاربر فقط پرچم، کشور و درصد سلامت را می‌بیند (نوع پروتکل نمایش داده نمی‌شود).

قواعد مسیریابی (مهم):

* **Fail-closed**: وقتی کانفیگ پروکسی دارد، ترافیک فقط از همان پروکسی خارج می‌شود؛ اگر پروکسی مرده باشد اتصال خطا می‌گیرد و **هرگز** بی‌صدا به مسیر مستقیم (آی‌پی خود سرور) برنمی‌گردد.
* هر نوع ترافیک (TLS، HTTP ساده، DNS روی TCP و...) از تونل پروکسی عبور می‌کند؛ نوع ترافیک تصمیم نمی‌گیرد پروکسی استفاده شود یا نه.
* دامنه‌ی مقصد اول به خود پروکسی داده می‌شود (DNS از سمت پروکسی حل می‌شود) و فقط اگر پروکسی دامنه را نپذیرد، یک‌بار با IP محلی تلاش می‌شود.
* با چند پروکسی (Multi-Location) تا ۳ تلاش با Failover انجام می‌شود؛ پروکسی‌های ناسالم موقتاً در Cooldown قرار می‌گیرند و بعد به‌صورت خودکار برمی‌گردند.
* اگر به‌روزرسانی مخزن موقتاً شکست بخورد، آخرین لیست سالم حفظ می‌شود و داشبورد بدون رفرش‌کردن صفحه وضعیت را نشان می‌دهد.

پروکسی دلخواه با هشدار خروج از محدوده امن نمایش داده می‌شود. راه‌اندازی باکت و محل دقیق ثابت کد در [PROXY-REPOSITORY.md](PROXY-REPOSITORY.md) آمده است.
