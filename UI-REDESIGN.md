# Lumen Orbit UI redesign

## Replaced patterns
The previous v28 panel used a compact right command rail, a four-card dashboard grid, equal-priority status rows, and a two-zone route form. Lumen Orbit replaces these with a left task navigator, global context bar, narrative service-health stage, quick-delivery workspace, asymmetric live pulse, progressive technical disclosure, and responsive drawer navigation.

## Information architecture
- Operate: Today, Routes, Delivery groups, Subscriptions
- Understand: Live sessions, Traffic story, Timeline, Issues
- Manage: Trust center, Connection lab, Settings

All API routes and live-data element contracts are preserved. Managed proxy health remains visible while operational issues are elevated without changing the primary VLESS/WebSocket route.
